# Wagent Ai design system

People check token mints on a laptop in an evening workspace, then continue setup in a phone chat. Keep the supplied W logo, near-black violet-tinted surfaces, and violet primary actions; Solana mint green identifies the network, selected navigation, positive changes, and available capability states. Use OKLCH tokens and readable light text. Reserve red for errors and negative changes. Wallet setup names Binance Wallet explicitly, distinguishes its EVM workspace identity from its Solana owner account, and provides inline browser/extension guidance when it is not detected. Wallet selection never silently switches to another installed wallet after a disconnect.

The overview leads with a precise two-line headline and a structural setup path, then workspace status, a real token table, and a future-feature list. Builder and Connections use numbered inline sections. Agent creation passes the new version to WhatsApp setup. A paired chat has a prominent wallet setup action. WhatsApp trading shows one active step at a time: Connect wallet, Add SOL, Approve limits. Keep custody consent before creating/funding the wallet, show a precise one-time SOL transfer review before opening the owner wallet, and place exchange transfer instructions in an expandable alternative. Show real balance and permission status in the persistent side panel; expose advanced fee/slippage fields progressively while summarizing their selected values. Keep revocation and withdrawals reachable at every step. The explorer provides explicit submit search, mint copy, watchlist stars, liquidity filters, pool age, and external research links. Missing data stays missing; cached data is labelled with its original fetch time. Upcoming features have dedicated explanatory screens instead of usable-looking trade forms. A permanent sidebar collapses behind a menu on mobile. Dense tables scroll inside their own region.

Use Segoe UI/system sans, tabular numeric metrics, varied spacing, subtle one-pixel borders, and 7–12px corners. Preserve the original raster logo and favicon. No gradient text, decorative glass, fake charts, or casino treatment. Motion is limited to short state changes and respects reduced motion. MetaMask is clearly an account identity; do not style an EVM address as a connected Solana trading wallet. Live prices are USD quotes and SOL is the chain currency. Manual trading uses an inline form beside a review panel, then explicit wallet approval. WhatsApp trading uses numbered owner/custody/permission steps beside a persistent limits summary and revoke control. State the server-held key and application-enforced limits before consent. Render the exact signature message inline. Show a fixed owner recipient for withdrawals, with a separate signature action. Alerts use a rule/activity list beside an inline form. Missing provider keys and offline workers have visible setup states. Collapse forms into one column on small screens.
